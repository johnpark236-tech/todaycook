# Recipe image guide

Core prompt direction: photorealistic Korean home-cooked food, bright natural daylight, warm modern Korean home table, clean ceramic tableware, centered dish, realistic steam, no people, hands, text, logo, watermark, branded packaging, or restaurant branding.

Use landscape 4:3, crop to 960×720, export WebP around quality 85, and keep the main food near the center. Filenames must match the recipe image path. Record source and usage in `assets/recipes/manifest.json`. Do not copy images from search engines, blogs, or restaurant sites.

Ten core images are AI-generated. Other current recipe files are explicit category placeholders made from project-owned assets; replace them with dish-specific images over time.
