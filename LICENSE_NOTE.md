# Asset and source notes

Application source code was created for the TodayCook project. The ten core food photographs under `assets/recipes/` are AI-generated project assets. Files identified as category placeholders in `assets/recipes/manifest.json` are derived copies of those project-owned assets and should be replaced with dish-specific images in a later content pass. The two supplied design-reference PNG files are retained only as project references and are not used by the production app.
